# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork this repository and create a branch for your changes.
2. Make your changes and test the simple interest calculator where applicable.
3. Commit your changes with a clear commit message.
4. Push your branch to your fork and open a pull request describing your changes.

## Reporting bugs and suggesting improvements

Open a GitHub issue describing the problem or suggestion. For bugs, include the steps to reproduce the issue and the expected and actual results.

Please follow the project's Code of Conduct when participating.
