# Simple Interest Calculator

A Bash script that calculates simple interest using values entered by the user.

## Inputs
- Principal amount
- Annual rate of interest (%)
- Time period in years

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Example
Principal: 1000
Rate: 5%
Time: 2 years
Simple Interest: 100

## Usage
Run the script using:
bash simple-interest.sh
